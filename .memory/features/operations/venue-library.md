Operations > Venues stores operational venue intel for event crews.

CRITICAL: `access_notes` / "Access instructions" means photographer/crew PRODUCTION access — loading dock, service entry, bump-in, lifts, security sign-in, space for equipment (lighting, backdrops, printers). It must NEVER describe wheelchair/disability accessibility. The venue-ai-lookup edge function prompt is explicitly instructed accordingly.

`parking_access` = crew vehicle parking/unload, height limits, entry points.
